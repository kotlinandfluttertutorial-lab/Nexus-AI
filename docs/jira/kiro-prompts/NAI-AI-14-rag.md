## Architecture Rules

- Each pipeline stage is a separate module with its own interface.
- Document ID, chunk ID, source, and page metadata are preserved through every stage.
- Context size passed to the LLM is bounded by a configurable `MAX_CONTEXT_TOKENS` setting.
- Empty retrieval returns a structured empty result — the LLM is never called with fabricated context.
- Stage failures return typed errors — no silent skips.
- `FakeVectorStore` and `FakeEmbeddingProvider` are used in all unit tests.

## Implementation Task

### Pipeline Stages

```
Document
    ↓  [1. Loading]
Raw Text + Metadata
    ↓  [2. Chunking]
List[DocumentChunk]
    ↓  [3. Embedding]
List[DocumentChunk with embedding]
    ↓  [4. Storage]
VectorStore
    ↓  [5. Retrieval]
List[SearchResult]
    ↓  [6. Query Rewriting] (optional)
Rewritten Query
    ↓  [7. Context Assembly]
BoundedContext
    ↓  [8. Generation]
RAGResponse (answer + sources)
```

### 1. Document Loader (`backend/rag/ingestion/loader.py`)

- Supports `.txt`, `.pdf` (via `pypdf`), `.md`
- Returns `RawDocument(document_id, source, content, metadata: dict)`
- Raises `ExtractionError` on unsupported format or parse failure

### 2. Text Splitter (`backend/rag/ingestion/splitter.py`)

- Wraps `RecursiveCharacterTextSplitter` with configurable `chunk_size` and `chunk_overlap`
- Returns `list[DocumentChunk]` with `chunk_id`, `document_id`, `source`, `page`, `content`

### 3. Embedding Service (`backend/rag/embedding/embedding_service.py`)

- `EmbeddingProvider` protocol: `embed(texts: list[str]) -> list[list[float]]`
- `OpenAIEmbeddingProvider` implementation
- `FakeEmbeddingProvider` for tests (returns fixed-dimension zero vectors)

### 4. Ingestion Pipeline (`backend/rag/ingestion/pipeline.py`)

Orchestrates Load → Chunk → Embed → Store for a given document path.

### 5. Retrieval Service (`backend/rag/retrieval/retrieval_service.py`)

- `retrieve(query: str, top_k: int, filters: dict | None) -> list[SearchResult]`
- Optional query rewriting: if `top_k` results have avg relevance < threshold, rewrite query and retry once

### 6. Context Assembler (`backend/rag/retrieval/context_assembler.py`)

- Assembles retrieved chunks into a context string
- Truncates at `MAX_CONTEXT_TOKENS` characters
- Returns `AssembledContext(text: str, sources: list[SourceReference], truncated: bool)`

### 6. Hybrid Search (optional stage)

Implement `backend/rag/retrieval/hybrid_retriever.py`:
- Combines semantic vector search with BM25 keyword search using `rank_bm25`.
- Merges and re-ranks results using Reciprocal Rank Fusion (RRF).
- Configurable via `RETRIEVAL_MODE = "semantic" | "hybrid"` environment variable.
- Falls back gracefully to semantic-only when BM25 index is not available.

### 7. RAG Pipeline (`backend/rag/pipeline.py`)

Orchestrates Retrieve → Assemble → Generate.
Returns `RAGResponse(answer: str, sources: list[SourceReference], empty_retrieval: bool)`.

### 8. FastAPI Endpoint

Add `POST /v1/rag/query` to the FastAPI service:
- Accepts `RAGQueryRequest(question: str, top_k: int = 5, document_ids: list[str] | None = None)`
- Returns `RAGResponse`

## Acceptance Criteria

| # | Criterion |
|---|---|
| AC1 | Documents are loaded and split into chunks with configurable `chunk_size` and `chunk_overlap`. |
| AC2 | Embeddings are generated for each chunk and stored in the vector store. |
| AC3 | Semantic similarity search retrieves top-K relevant chunks. |
| AC4 | Query rewriting is attempted when initial retrieval average relevance is below threshold. |
| AC5 | Assembled context includes source document ID, source path, and page references. |
| AC6 | Context size is bounded by `MAX_CONTEXT_TOKENS` — assembly truncates and sets `truncated=True`. |
| AC7 | Empty retrieval returns `RAGResponse(empty_retrieval=True)` — generation is skipped. |
| AC8 | Unsupported document format raises `ExtractionError` — not a silent skip. |
| AC9 | Hybrid search combines semantic and BM25 keyword results via Reciprocal Rank Fusion when `RETRIEVAL_MODE=hybrid`. |
| AC10 | Each pipeline stage is tested independently using `FakeVectorStore` and `FakeEmbeddingProvider`. |
