## Security Rules (Non-Negotiable)

- **Never** hardcode API keys, passwords, JWT secrets, encryption keys, or production credentials.
- Do not log tokens, passwords, or any sensitive authentication data.
- Use secure storage appropriate to the architecture (EncryptedSharedPreferences / Keystore).
- Do not expose raw security exceptions to users — map to safe domain error types.
- Preserve HTTPS requirements for Stage and Production.
- Follow all rules in `.kiro/steering/05-security-standards.md`.

## Implementation Task

Create or improve the authentication foundation without duplicating existing infrastructure:

- Authentication state representation (authenticated / unauthenticated / expired)
- Secure token storage
- Token refresh / session expiration handling
- Logout — clears all authentication state
- Authentication error types
- Network authentication integration
