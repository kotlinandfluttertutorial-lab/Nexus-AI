## Architecture Rules

- Model weight files (`*.bin`, `*.safetensors`, `*.pt`, `*.gguf`) are never committed to Git.
- `HFTextGenerationProvider` and `HFEmbeddingProvider` implement domain protocols.
- Hugging Face `transformers.*` types do not appear outside `backend/model-serving/huggingface/`.
- Device placement is explicit — always specify `device` or `device_map="auto"`.
- Minimum RAM/VRAM requirements are documented as code comments and in `README.md`.
- CI tests use a tiny test model (`hf-internal-testing/tiny-random-gpt2`) or a `FakeHFProvider` — never download full models in CI.

## Implementation Task

### 1. Model Selection

Choose models appropriate for development hardware:

| Role | Suggested Model | License |
|---|---|---|
| Text generation | `microsoft/phi-3-mini-4k-instruct` or `TinyLlama/TinyLlama-1.1B-Chat-v1.0` | MIT / apache-2.0 |
| Embeddings | `sentence-transformers/all-MiniLM-L6-v2` | apache-2.0 |

Document the chosen models, licenses, and hardware requirements in
`backend/model-serving/huggingface/README.md`.

### 2. HFTextGenerationProvider

Implement in `backend/model-serving/huggingface/providers/hf_text_generation.py`:
- Loads `AutoModelForCausalLM` and `AutoTokenizer` from the given `model_id`
- Implements `LLMProvider.complete()` synchronously (wrapped in `run_in_executor` for async)
- Implements `LLMProvider.stream()` using `TextIteratorStreamer` in a thread

### 3. HFEmbeddingProvider

Implement in `backend/model-serving/huggingface/providers/hf_embedding.py`:
- Uses `SentenceTransformer` to embed a list of texts
- Returns `list[list[float]]` with `normalize_embeddings=True`

### 4. Performance Comparison

Create `learning/09-huggingface/benchmark.py` that:
- Runs the same 5 prompts through `HFTextGenerationProvider` and the OpenAI/Gemini adapter
- Records time-to-first-token and total latency
- Outputs a comparison table

### 5. Datasets & Spaces Exploration

Create `learning/09-huggingface/datasets_demo.py`:
- Load a small public dataset from the Hub using `datasets.load_dataset()` (e.g. `"imdb"` or `"squad"` sample split).
- Print dataset structure: feature names, split sizes, and a sample row.
- Document in `README.md`: what Spaces are and how they relate to model demos.

### 6. FakeHFProvider

Create `backend/model-serving/huggingface/tests/fake_hf_provider.py` for unit tests.
