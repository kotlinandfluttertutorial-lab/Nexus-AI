## Architecture Rules

- `VectorStore` protocol lives in `backend/rag/vector_store/interface.py` — no ChromaDB imports.
- `ChromaVectorStoreAdapter` lives in `backend/rag/vector_store/chroma_adapter.py`.
- `FakeVectorStore` lives in `backend/rag/vector_store/fake_vector_store.py`.
- In production, always use `chromadb.PersistentClient` — never in-memory client in production.
- Telemetry is disabled: `Settings(anonymized_telemetry=False)`.
- Raw ChromaDB distance scores are normalized to `[0, 1]` relevance before returning.
- ChromaDB types never appear outside `chroma_adapter.py`.

## Implementation Task

### 1. Domain Models

Create in `backend/rag/vector_store/models.py`:

```python
@dataclass
class DocumentChunk:
    chunk_id: str
    document_id: str
    source: str
    page: int | None
    content: str
    embedding: list[float]
    metadata: dict

@dataclass
class SearchResult:
    chunk: DocumentChunk
    relevance_score: float  # 0.0 (irrelevant) to 1.0 (identical)
    distance: float         # raw distance from ChromaDB (for diagnostics)
```

### 2. VectorStore Interface

Create `backend/rag/vector_store/interface.py`:

```python
class VectorStore(Protocol):
    async def insert(self, chunks: list[DocumentChunk]) -> None: ...
    async def search(
        self,
        query_embedding: list[float],
        top_k: int = 5,
        filters: dict | None = None,
    ) -> list[SearchResult]: ...
    async def delete(self, document_id: str) -> None: ...
    async def count(self) -> int: ...
    async def collection_name(self) -> str: ...
```

### 3. ChromaVectorStoreAdapter

Implement `backend/rag/vector_store/chroma_adapter.py`:
- Constructor: `(persist_directory: str, collection_name: str)`
- Use `chromadb.PersistentClient` with `Settings(anonymized_telemetry=False)`
- `insert()`: uses `collection.upsert()` — idempotent on `chunk_id`
- `search()`: calls `collection.query()`; applies `where` filter when `filters` is given
- `delete()`: queries all chunk IDs for `document_id`, then calls `collection.delete(ids=[...])`
- Normalizes cosine distance: `relevance = max(0.0, 1.0 - distance / 2.0)`

### 4. FakeVectorStore

Implement `backend/rag/vector_store/fake_vector_store.py`:
- In-memory `list[DocumentChunk]` backing store
- Constructor accepts `fixed_results: list[SearchResult] | None` for search overrides
- Full `insert`, `search`, `delete`, `count` implementation

### 5. Collection Configuration

Create `backend/rag/vector_store/collection_config.py`:
- `DEFAULT_COLLECTION = "nexus_ai_documents"`
- `PERSIST_DIRECTORY` loaded from `os.environ.get("CHROMA_PERSIST_DIR", "./data/chroma")`

### 6. Demo

Create `learning/15-vector-databases/chroma_demo.py`:
- Inserts 10 document chunks with mixed `document_id` values
- Runs 3 similarity searches, prints results with scores
- Demonstrates metadata filter (restrict by `document_id`)
- Deletes one document; confirms count decreases
