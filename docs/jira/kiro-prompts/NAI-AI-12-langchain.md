## Architecture Rules

- `langchain.*` types must not appear in `domain/`, `api/`, or `application/` layers.
- LangChain components are wrapped in adapters in `backend/agent-runtime/langchain/adapters/`.
- Prompt templates live in `backend/agent-runtime/langchain/prompts/` — not inline strings.
- The RAG chain uses LCEL: `retriever | prompt | llm | output_parser`.
- Streaming propagates through the chain — `astream()` is used for streaming chains.
- Document metadata (source, page) is preserved through the entire chain.
- Tests use `FakeListChatModel` — zero real API calls.

## Implementation Task

### 1. RAG Chain (LCEL)

Create `backend/agent-runtime/langchain/chains/rag_chain.py`:
- Accepts injected `llm: BaseChatModel` and `retriever: VectorStoreRetriever`
- Uses `ChatPromptTemplate.from_template(RAG_TEMPLATE)` with `{context}` and `{question}` vars
- Pipeline: `{"context": retriever, "question": RunnablePassthrough()} | prompt | llm | StrOutputParser()`
- Streaming: implement `astream(question: str) -> AsyncIterator[str]`

### 2. Document QA Chain

Create `backend/agent-runtime/langchain/chains/document_qa_chain.py`:
- Loads a document list, formats them as context, asks a question
- Returns answer + list of source references (document source + page)

### 3. LangChain Tool

Create `backend/agent-runtime/langchain/tools/search_tool.py`:
- Uses `@tool` decorator
- Description: `"Search the document store for relevant information"`
- Implementation calls the existing retrieval service

### 4. LangChain LLM Adapter

Create `backend/agent-runtime/langchain/adapters/langchain_llm_adapter.py`:
- Wraps `BaseChatModel` → `LLMProvider` protocol
- `complete()` calls `llm.ainvoke()`
- `stream()` calls `llm.astream()`
- Maps `langchain_core.exceptions` to domain `AIError` types

### 5. Prompt Templates

Create `backend/agent-runtime/langchain/prompts/`:
- `rag_template.txt` — versioned RAG system + user template
- `qa_template.txt` — document QA template
- `prompts.py` — loads templates from files; each has a `version` constant

### 6. Demo

Create `learning/12-langchain/rag_demo.py`:
- Loads sample documents
- Builds RAG chain with `FakeListChatModel` (or real model with `--live` flag)
- Runs 3 questions; prints answers and source references
