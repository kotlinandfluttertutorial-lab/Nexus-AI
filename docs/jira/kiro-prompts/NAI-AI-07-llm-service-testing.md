## Architecture Rules

- All automated tests use fake/stub providers — zero real API calls.
- Tests are deterministic: same result on every run regardless of network state.
- Streaming tests collect the full SSE event sequence and assert ordering.
- Bruno/Postman collection documents each endpoint with example request/response bodies.
- Test report is generated via `pytest --tb=short -v` — output is captured as evidence.
