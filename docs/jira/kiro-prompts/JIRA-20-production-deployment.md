## Environments

## Implementation Task

Configure production-readiness without changing unrelated application behavior:

- Three build variants (local/debug, stage, production/release) or equivalent per spec
- Environment-specific API endpoints isolated per build variant
- Secrets externalized for all environments (no hardcoded values)
- R8/ProGuard rules reviewed and configured for release
- Release build signing configuration (keystore via CI secrets)
- ProGuard keep rules for domain entities, serialization, Hilt
- Production logging restrictions verified
- Network security config reviewed for production
- Android component export flags reviewed

## Security Requirements (Non-Negotiable)

- No production credentials, API keys, or keystore passwords in source control.
- API keys supplied via CI secrets injected as `BuildConfig` fields.
- Keystore credentials supplied via CI secrets — keystore file itself also excluded from Git.
- `android:exported` flags reviewed on all components.
- `android:allowBackup` or explicit backup rules exclude sensitive data.
- Network security config enforces HTTPS in production.
- Production builds have no DEBUG logging.
