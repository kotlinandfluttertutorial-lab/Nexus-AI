## Architecture Rules

- API keys are loaded from environment variables via `pydantic-settings` — never hardcoded.
- Provider SDK calls are isolated behind a service layer — route handlers never call SDK directly.
- All settings come from environment; provide `.env.example` with placeholder values.
- Use structured error responses: `{"error": {"code": "...", "message": "..."}}`.
- This is a Python backend workstream — Android architecture rules do not apply here.

## Implementation Task

Create a text-generation service with at least one hosted provider (OpenAI or Gemini) behind a
simple service layer. Expose a generation endpoint that accepts a prompt and generation parameters.

### Deliverables

- `backend/fastapi-service/` (or `learning/01-genai/`) with:
  - Generation settings loaded from environment
  - A service class that calls the hosted provider
  - A FastAPI or plain Python endpoint / script that accepts prompt + temperature + max_tokens
  - Validation that rejects out-of-range temperature or negative max_tokens
  - `.env.example` with all required keys documented

## Acceptance Criteria

| # | Criterion |
