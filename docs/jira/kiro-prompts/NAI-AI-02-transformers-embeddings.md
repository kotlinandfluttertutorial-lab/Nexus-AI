## Description

Explore transformer architecture through hands-on experiments: tokenization, vocabulary sizes,
positional encoding, self-attention mechanics, and multi-head attention. Generate text embeddings
using Sentence Transformers. Measure and compare semantic similarity between sentences using cosine
distance. Document all results and findings.

## Implementation Task

Build a set of exploration scripts and a reusable embedding utility demonstrating:

1. **Tokenization experiment**: load a tokenizer, encode sample sentences, report token IDs,
   token count, and vocabulary size.
2. **Positional encoding**: visualise or print the positional encoding vectors for a short
   sequence to show how position information is injected.
3. **Self-attention walkthrough**: implement or trace a single-head scaled dot-product attention
   step with small toy vectors; show how Query, Key, and Value matrices combine.
4. **Multi-head attention**: extend to multi-head attention — split into `n_heads` subspaces,
   compute attention per head, concatenate results.
5. **Embedding generation**: use `sentence-transformers/all-MiniLM-L6-v2` to embed sentences
   and output embedding dimension.
6. **Semantic similarity**: compute cosine similarity between sentence pairs. Verify that
   semantically similar pairs score measurably higher than unrelated pairs.
7. **Documentation**: write a short `README.md` in `learning/02-transformers-embeddings/`
   recording the models used, their licenses, embedding dimensions, and key findings.
