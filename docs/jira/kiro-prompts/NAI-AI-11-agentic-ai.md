## Architecture Rules

- Agent logic lives in `backend/agent-runtime/agents/` — not inside FastAPI route handlers.
- Agent uses the `LLMProvider` interface — never calls a provider SDK directly.
- Tools are looked up from a `ToolRegistry` by name — agent does not own tool implementations.
- All tool inputs are validated against the tool's JSON schema before execution.
- Maximum step count is defined at construction time and enforced unconditionally.
- Cancellation is handled via `asyncio.CancelledError` — the agent propagates it cleanly.
- Execution trace is a list of `TraceStep` objects attached to `AgentResult`.

## Implementation Task

### 1. Domain Models

Create in `backend/agent-runtime/agents/models.py`:

```python
@dataclass
class AgentTask:
    task_id: str
    description: str
    context: dict

@dataclass
class TraceStep:
    step_number: int
    thought: str
    tool_name: str | None
    tool_input: dict | None
    tool_output: str | None
    error: str | None

@dataclass
class AgentResult:
    task_id: str
    status: AgentStatus   # SUCCESS | FAILURE | STEP_LIMIT_REACHED | CANCELLED
    output: str
    steps_taken: int
    trace: list[TraceStep]
    error: str | None = None
```

### 2. Tool Registry

Create `backend/agent-runtime/agents/tool_registry.py`:
- `register(name, description, parameters_schema, execute_fn)`
- `get(name) -> ToolDefinition | None`
- `list_tools() -> list[ToolDefinition]`

### 3. Agent Execution Loop

Create `backend/agent-runtime/agents/agent_executor.py`:

```
loop:
  1. Build prompt: task + history + available tools
  2. Call LLMProvider.complete() for planning/tool selection
  3. Parse response: thought + optional tool_call
  4. If tool_call:
       a. Validate input against schema
       b. Execute with asyncio.wait_for(timeout)
       c. Record result in trace
  5. If no tool_call or "FINISH": break
  6. If step_count >= max_steps: return STEP_LIMIT_REACHED
```

### 4. Demo Task

Create `learning/11-agentic-ai/demo.py`:
- Register 2–3 simple tools (e.g. `get_current_time`, `calculate`, `search_documents`)
- Create an `AgentTask` with a multi-step goal
- Run the agent and print the execution trace

### 5. FastAPI Endpoint

Add `POST /v1/agents/run` to the FastAPI service:
- Accepts `AgentRunRequest(task: str, max_steps: int = 10)`
- Returns `AgentRunResponse` containing `AgentResult`
