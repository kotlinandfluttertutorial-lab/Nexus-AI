## Architecture Rules

- Structured output responses are validated against a Pydantic model before being returned.
- Tool calling is a request-response cycle: model requests tool → caller executes → result fed back.
  The provider adapter handles the cycle internally or exposes the `ToolCall` event.
- Vision input is a `content` list containing text and image parts — not a top-level field.
- Features unsupported by a given provider return `{"error": {"code": "feature_not_supported", "message": "..."}}` — never a 500.
- All new domain model fields use `Optional` with explicit `None` defaults — no breaking changes
  to existing callers.

## Implementation Task

### 1. Structured JSON Output

Extend `ChatRequest` with:
```python
response_format: Literal["text", "json_object"] | None = None
json_schema: dict | None = None   # JSON Schema for the expected output
```

In the provider adapters, pass `response_format={"type": "json_object"}` to the SDK when set.
Validate the model's response against `json_schema` using `jsonschema.validate()`.
Return a `StructuredOutputResponse` that includes `parsed: dict` alongside the raw `content`.

### 2. Streaming (end-to-end verification)

Verify the full chain: `ChatRequest(stream=True)` → provider adapter → SSE → client.
Add an integration test that collects all SSE chunks and asserts:
- First event is a token (not `[DONE]`)
- Last event is `[DONE]`
- Concatenated tokens form a non-empty string

### 3. Function / Tool Calling

Extend `ChatRequest` with:
```python
tools: list[ToolDefinition] | None = None
```

`ToolDefinition`:
```python
class ToolDefinition(BaseModel):
    name: str
    description: str
    parameters: dict   # JSON Schema
```

Provider adapter passes tools to the SDK. When the model returns a tool call:
- Return a `ChatResponse` with `tool_calls: list[ToolCall]`
- Caller feeds result back via a follow-up `ChatRequest` with a `tool` role message

Demonstrate in `learning/10-advanced-llm/tool_calling_demo.py`.

### 4. Vision Input

Extend `Message.content` to accept:
```python
content: str | list[ContentPart]  # ContentPart = text | image_url
```

Add `ImageUrlPart`:
```python
class ImageUrlPart(BaseModel):
    type: Literal["image_url"]
    image_url: dict   # {"url": "https://..." | "data:image/...;base64,..."}
```

Demonstrate in `learning/10-advanced-llm/vision_demo.py`.
