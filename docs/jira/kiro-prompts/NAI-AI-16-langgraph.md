## Architecture Rules

- Every graph has a `TypedDict` state — no ad-hoc dicts.
- Node functions are pure: they accept state and return a partial state update dict only.
- Routing logic lives in standalone routing functions passed to `add_conditional_edges` — never inside node functions.
- Every looping graph has a `step_count: int` in its state and a guard edge that returns `"end"` when `step_count >= max_steps`.
- Human-approval is implemented as `interrupt_before=["sensitive_node"]` on `graph.compile()` — not as a blocking call inside a node.
- Checkpointing uses `MemorySaver` in development; `SqliteSaver` for persistence.
- LangGraph types do not appear outside `backend/agent-runtime/langgraph/`.

## Implementation Task

### 1. Research Graph State

Create `backend/agent-runtime/langgraph/state/research_state.py`:

```python
from typing import TypedDict, Annotated
import operator

class ResearchState(TypedDict):
    query: str
    messages: Annotated[list, operator.add]   # accumulates across steps
    documents: list[str]
    summary: str
    step_count: int
    requires_approval: bool
    approved: bool
    error: str | None
```

### 2. Node Functions

Create `backend/agent-runtime/langgraph/nodes/`:
- `planner.py` — `make_planner_node(llm)` returns an async node that adds a plan to messages
- `researcher.py` — `make_researcher_node(llm, retrieval_service)` searches documents; increments `step_count`
- `summarizer.py` — `make_summarizer_node(llm)` produces the final `summary`
- `human_review.py` — sets `requires_approval=True`; waits for external `approved=True` injection

### 3. Routing Function

Create `backend/agent-runtime/langgraph/graphs/research_graph.py`:

```python
def should_continue(state: ResearchState) -> str:
    if state["step_count"] >= MAX_STEPS:
        return "end"
    if state.get("requires_approval") and not state.get("approved"):
        return "human_review"
    if state.get("summary"):
        return "end"
    return "researcher"
```

### 4. Graph Assembly

```python
graph = StateGraph(ResearchState)
graph.add_node("planner", planner_node)
graph.add_node("researcher", researcher_node)
graph.add_node("human_review", human_review_node)
graph.add_node("summarizer", summarizer_node)
graph.set_entry_point("planner")
graph.add_edge("planner", "researcher")
graph.add_conditional_edges("researcher", should_continue, {...})
graph.add_edge("human_review", "researcher")
graph.add_edge("summarizer", END)
app = graph.compile(checkpointer=MemorySaver(), interrupt_before=["human_review"])
```
